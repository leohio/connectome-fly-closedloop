# ハエ飛行制御の最小複素線形モデル (P5 草稿、2026-09-02)

fly-integrated の実験群 (統合28〜39) で発見した事実を、一つの離散時間線形系から再導出する。
1 羽ばたき (4.908 ms) を 1 ステップとし、状態は羽ばたき平均の遅い成分で書く。

## 1. 身体 (P1、実測同定)

```
x̄[k+1] = F x̄[k] + G1 ū[k] + G0 ū[k+1] + c
x̄ = [e_b0, e_b1, ωx, ωy, ωz, z, vz, vx, vy]     ū = 翅変調 5 次元 (羽ばたき内平均)
```

- 同定精度: 1 ステップ R² = 姿勢 0.96/1.00、高度 1.00、並進 0.97〜0.99 (ヨー角速度のみ 0.42)
- 15 羽ばたき先の多段予測誤差 0.14
- **支配的不安定モード**: 複素対 |λ| = 1.033、周期 124 ms、倍加 105 ms。
  主成分はピッチ角速度 ωy と前進速度 vx の結合 — 昆虫ホバリングの縦不安定振動モード
- 位置モードは中立 (|λ| = 1.003)、ロール/ヨー振動モードは安定 (0.98)

**教訓**: 状態を位相 0 の瞬時値で取ると偽固有値 |λ| = 2.6 が出る (翅関節の隠れ状態)。
遅い成分 = 羽ばたき平均で定義することが必須。

## 2. 筋・感覚・制御 (実測値の移植)

```
筋 (単収縮 τ=4.25ms):  u_end[k] = 0.315 u_end[k−1] + 0.685 u_cmd[k]
                       ū[k]    = 0.593 u_end[k−1] + 0.407 u_cmd[k]
感覚 (実回路の復号):   ω_f[k]  = 0.664 ω_f[k−1] + 0.336 · diag(0.80, 0.92, 0.91) ω̄[k−1]
                       ω̂[k]   = ω_f[k−1−d]        (純遅延 d 羽ばたき、実回路は d ≈ 1〜2)
制御 (1 羽ばたき 1 回): u_cmd[k] = clip(U_trim + 0.35 tanh(K y[k−1] + b))
                       y = [−δz/5, −vz/30, e_b0, e_b1, ω̂/20]
```

## 3. 閉ループ (P2)

上を合成した行列 T のスペクトルは 2 種類に分かれる:

| モード | |λ| | 意味 |
|---|---|---|
| 遅いドリフト (z, vx, vy) | 1.002〜1.007 | 高度・位置が漂う。ES-K 1.0017 (倍加 2 s) vs 学習K 1.007 (倍加 0.5 s) — 「学習 K は高度維持が粗い」の説明 |
| 速い姿勢モード (周期 ~90 ms) | 遅延で単調増加 | 飛行を殺すのはこちら |

ES-K の速い姿勢モード: d0 0.972 / d1 0.993 / **d2 1.019** / d3 1.044 / d4 1.059
→ 予測される壁 d=2。同じ座標の非線形閉ループ実走行: d0,d1 完走、**d2 で 1.43 s 墜落**、
d3 0.72 s、d4 0.55 s。統合36 で経験的に見つけた「遅延の壁」が固有値から出る。

遅延 2 で訓練した報酬学習 K は速いモードが d3 まで 0.985 以下 (d4 で 1.008) →
実走行 d0〜d4 完走。**遅延マージン訓練が実回路 (d≈1〜2) への転移を成立させた理由**。
ただしこの制御器は tanh が飽和したバンバン制御 (引数 +5) で、線形化は参考値。

**限界**: ホバーは固定点ではなく振幅 ~0.1 rad・~11 Hz のリミットサイクル。2 軌道差の
成長率は d≤1 で ≈1.00 (サイクルの位相方向)、d≥2 で正。固定点線形化は「傾向と壁の位置」を
与え、絶対値は与えない。整数ビート断面の Floquet 有限差分は失敗 (準周期性)。

## 4. コネクトームが決めるもの (P3)

感覚行列 S (筋 × 3 軸) の各行は ±C_PHASE の符号パターン = 求心性クラスの符号化ベクトル
`b_j = [side_j, 1, side_j cos 2π pref_j]` に一致する。MN の位相は入力の重心ではなく、
不応期 (0.9 周期) 明け直後に最初に到着する求心性クラスへの位相固定 (円周写像の不動点):

```
θ_{k+1} = min{ φ_j : φ_j ∈ (θ_k + 0.9, θ_k + 1] (mod 1), W_ij ≥ w_min }
```

この 1 次元の構造計算だけで実配線の復号誤差 0.122 (実測 0.113)、条件数 2.28 (実測 2.33) を
再現する。実配線を完全ヌル 100 個から分離する不変量は **MN 内入力の符号化コヒーレンス**
(ロール成分 = 左右同側性: 実 0.946 vs ヌル 0.413、0/100 が実配線に届かない)。
悪条件ヌルの最弱方向は一貫してロール∓ヨーで、クラスタ ½ に固定した MN を失うと
ロールとヨーが分離できない (符号化でクラスタ 0 は b = [side, 1, side])。

**結論**: 配線特異性の線形代数的正体は「同側にまとまった求心性→MN 結線が各 MN を単一の
符号化クラスに位相固定させ、クラスの多様性 (両側 × 両クラスタ) がロール・ピッチ・ヨーを
分離する良条件の S を作る」こと。ただしヌル集団内の誤差ばらつきは静的代理では予測できず
(ρ ≈ 0)、ノイズ下の位相固定の不安定化 (力学) が支配する。

## 5. 歩行 (P4) — 位相振動子モデルは当てはまらない

脚位相の複素コヒーレンス行列 Z_ij = ⟨exp(i(φ_i − φ_j))⟩ を直立を保った 2 ラン (5 s) で測ると、
脚の振動数が揃わず (前脚 3 Hz、他 6 Hz)、|Z_ij| = 0.02〜0.52 (雑音水準)、主固有値 2.0〜2.4/6、
Kuramoto フィット R² ≤ 0.12、ヤコビアンに正の実部 (+7)。脚は遊脚か接地に張り付いたまま
揺れているだけで (前脚遊脚率 0.9、中脚 0.1)、歩容は存在しない。

**結論**: 飛行に「羽ばたき」という搬送波があったのに対し、現在の歩行モデルには共通リズム
(脚 CPG) が無く、遅い成分を切り出す位相制御の枠組み自体が適用できない。
上の 1〜4 節の最小モデルは飛行系に限って成立する。歩行を同じ枠組みに載せるには、
腹髄の脚 CPG 回路をコネクトーム駆動で導入することが前提になる (未着手)。

**P4b (切り分け)**: 身体を切り離した腹髄単独 (MDN 150/300 Hz) でも脚 MN 群の集団発火は
ポアソン雑音と区別がつかず (帯域スペクトルの鋭さ・屈筋伸筋交代・脚間 |Z| すべて零仮説の
97.5 % 点以内)、リズムは腹髄側に存在しない。統合37 の歩行は身体反射による足踏みである。
点過程 LIF + MANC 配線では CPG は生成されず、細胞レベルの力学 (バースト性など) が必要。
