# 戦略: 位相制御 + 線形代数による簡略化 (phase_algebra)

策定: 2026-09-02。fly-integrated (このリポジトリ本体) で実験的に発見した事実を、
一つの線形固有値問題から再導出することを目指す。

## 核となる観察

飛行系のすべての信号は羽ばたき (約203 Hz) に位相固定されている:
ハルテア求心性は1周期1発、操舵MNも1周期1発、筋は単収縮で平滑化、身体はそれより遅い。
つまり系は「速い搬送波 (羽ばたき位相)」と「遅い包絡線 (姿勢・回転・高度)」の
二時間スケール系であり、ロックイン検波・動的フェーザと同じ構造を持つ。

→ 簡略化の座標: **1羽ばたき = 1ステップ の離散時間系**、回路状態は複素数 (位相と振幅)。

## 5層の分解

```
第1層 座標    z_j = r_j·exp(i·θ_j)  (ニューロン j の周期内発火位相)、身体はストロボ化
第2層 4行列   身体 x[k+1] = F x[k] + G a[k]
              感覚 z[k]   = H x[k−d] + noise   (H は複素行列、実配線が決める)
              復号 ω̂[k]  = W z[k]
              制御 a[k]   = K [x_vis; ω̂][k]   (筋単収縮は1次極として吸収)
第3層 合成    閉ループ行列 T、ホバリング安定 ⇔ スペクトル半径 ρ(T) < 1
第4層 配線    G_io = C (I − A)⁻¹ B のSVD、特異部分空間と回転符号化の整列角
第5層 歩行    脚位相の結合振動子、歩容 = 結合行列の固有ベクトル、ゲイン窓 = Hopf分岐
```

実測済み: H (統合36d: ゲイン0.8-0.92、τ=12ms、遅延1-2羽ばたき、ノイズstd1.9)、
W (measure_S の S)、K (bioflight_best / 学習K)。**未同定は F, G のみ。**

## 検証の規律

- 線形化の予測は必ず閉ループのスパイキング実験で検証してから主張する
- 実測済みの壁 (遅延3で墜落、歩行ゲイン0.2/0.26/0.4、単収縮なしで0.58s以下、
  配線特異性の消失) がそのまま検証データセットである
- 揚力の崖 (振幅±5%で崩壊) は機体の強い非線形であり、本計画の外。振幅1.0固定の
  動作点まわりに限定する
- ペロン・フロベニウス系 (非負行列前提) は抑制性結合がある時点で適用外

## P1 の結果 (2026-09-02)

状態 = 羽ばたき平均 [e_b0, e_b1, ωx, ωy, ωz, z, vz, vx, vy]、入力 = 翅変調 5 次元、
ARX `x̄[k+1] = F x̄[k] + G1 u[k] + G0 u[k+1] + c` を 255 サンプル (線形域内) で同定。

- 1ステップ予測 R²: e_b 0.96/1.00、z 1.00、vz 0.99、vx/vy 0.99/0.97 (ωz のみ 0.42)
- 多段予測 (保持軌道 6 本): 3/6/10/15 羽ばたき先で相対誤差 0.03/0.08/0.16/0.14
- **支配的不安定モード**: 複素対 |λ|=1.033 (arg ±14.3°)、周期 124 ms、倍加 21.5 羽ばたき
  (105 ms)、主成分 ωy(1.00)・ωx(0.26)・vx(0.22) — ピッチ角速度と前進速度が結合した
  縦の振動モード。統合36 で観測した「20 Hz 前後で成長するピッチ振動」と、
  昆虫ホバリングの飛行力学で知られる縦不安定振動モードに整合する
- 位置モード |λ|=1.003 (ほぼ中立)、ロール/ヨー振動モード 0.98 (安定)

**失敗の記録**: 初版は位相 0 の瞬時状態を使い |λ|=2.63 (1羽ばたきで倍加) を得たが、
線形予測が発散する一方で実軌道は有界であり偽固有値と判定。瞬時角速度は羽ばたき振動
(±40 rad/s) と翅関節の隠れ状態に支配され、9 次元では写像がマルコフにならない。
第1層の通り「遅い成分 = 羽ばたき平均」で状態を定義することが必須だった。
