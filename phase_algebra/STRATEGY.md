# 戦略: 位相制御 + 線形代数による簡略化 (phase_algebra)

策定: 2026-09-02。fly-integrated (このリポジトリ本体) で実験的に発見した事実を、
一つの線形固有値問題から再導出することを目指す。

## 核となる観察

飛行系のすべての信号は羽ばたき (約203 Hz) に位相固定されている:
ハルテア求心性は1周期1発、操舵MNも1周期1発、筋は単収縮で平滑化、身体はそれより遅い。
つまり系は「速い搬送波 (羽ばたき位相)」と「遅い包絡線 (姿勢・回転・高度)」の
二時間スケール系であり、ロックイン検波・動的フェーザと同じ構造を持つ。

→ 簡略化の座標: **1羽ばたき = 1ステップ の離散時間系**、回路状態は複素数 (位相と振幅)。

## 5層の分解

```
第1層 座標    z_j = r_j·exp(i·θ_j)  (ニューロン j の周期内発火位相)、身体はストロボ化
第2層 4行列   身体 x[k+1] = F x[k] + G a[k]
              感覚 z[k]   = H x[k−d] + noise   (H は複素行列、実配線が決める)
              復号 ω̂[k]  = W z[k]
              制御 a[k]   = K [x_vis; ω̂][k]   (筋単収縮は1次極として吸収)
第3層 合成    閉ループ行列 T、ホバリング安定 ⇔ スペクトル半径 ρ(T) < 1
第4層 配線    G_io = C (I − A)⁻¹ B のSVD、特異部分空間と回転符号化の整列角
第5層 歩行    脚位相の結合振動子、歩容 = 結合行列の固有ベクトル、ゲイン窓 = Hopf分岐
```

実測済み: H (統合36d: ゲイン0.8-0.92、τ=12ms、遅延1-2羽ばたき、ノイズstd1.9)、
W (measure_S の S)、K (bioflight_best / 学習K)。**未同定は F, G のみ。**

## P2 の結果 (2026-09-02)

閉ループ行列 T = [身体 F,G] ∘ [筋単収縮] ∘ [感覚: τ=12ms 一次遅れ + ゲイン + 純遅延 d] ∘
[制御則 K を動作点で線形化] を構成し (closed_loop.py)、速い姿勢モード (周期<300ms) と
遅いドリフトモード (位置・高度) を分けて評価した。検証は同じ座標・同じ感覚模型で
非線形閉ループを回す hover_growth.py / floquet_check.py。

**検証を通った予測**
- ES-K (統合31): 速い姿勢モード |λ| = d0 0.972 / d1 0.993 / **d2 1.019** / d3 1.043 / d4 1.059
  → 壁は d=2。実走行 (ノイズなし): d0,d1 4秒完走、**d2 1.43秒、d3 0.72秒、d4 0.55秒**。
  統合36 の安価ループ (d2 劣化、d3 墜落) とも整合。速いモードの周期 86-92 ms は
  P1 の機体不安定モード (124 ms) が制御で速められたもので、統合36 で観測した
  「20 Hz 前後で成長するピッチ振動」の理論的対応物
- 遅いドリフトモード: ES-K 1.0017 (倍加 2.0 s) vs 学習K 1.007 (倍加 0.5 s) vs
  es_takeoff 1.009-1.022 (倍加 0.2-0.4 s) — 「学習Kは高度維持が粗い (誤差 7 vs 0.5)」の説明
- 遅延2訓練の ES (es_takeoff_best) と遅延3訓練 (d3_best) の実走行の壁はそれぞれ d=3, d=4 で、
  訓練時の遅延マージン設定と一致 (ただし下記の通り絶対値の予測は外れている)

**検証を通らなかった点 (正直に)**
- es_takeoff 系の予測 |λ| は d0 から 1.008-1.05 (不安定) だが、実走行は d2/d3 まで
  4秒完走する。tanh 飽和ではない (引数 ±0.2、微分 0.97-1.00 を確認)。
  自分の動作点で線形化し直しても変わらない
- 原因は**ホバーが固定点ではないこと**: 全制御器で振幅 ~0.1 rad、7.5-13.5 Hz の持続振動
  (リミットサイクル) 上で飛んでいる。摂動あり/なしの2軌道差の成長率は生存ケースで
  一様に 1.00-1.01 で、これはサイクル上の位相ずれ (Floquet 乗数 1 の中立方向) を
  測っている。固定点の固有値で「1 をわずかに越える」ことはサイクル振幅に吸収され、
  壁はサイクル自体が不安定化する点に現れる
- 報酬学習の制御器 (v6 個体2) は tanh 引数 −1.4〜+5.0 で**完全飽和 (バンバン制御)**。
  線形化の対象外であり、その予測一致 (d3 まで安定) は根拠にしない

**帰結**: 固定点線形化は「遅延で壊れる順序と壁の位置」を再現するが、絶対値の
予測には**リミットサイクル周りの Floquet 解析** (サイクル周期 ~18 羽ばたきの
単ドロミー行列) が必要。これを P2b として計画に追加する。

## P3 の結果 (2026-09-02) — 配線特異性の線形代数的正体

### 機構の同定: MN の位相は「入力の重心」ではなく「最初に到着するクラス」
実配線の実測 S (9筋×3軸) の各行は ±C_PHASE の符号パターンに一致する
(例: b1_R → (−,+,−)、hg3_R → (−,+,+)、b1_L → (+,+,+))。これは求心性クラス
(側 ±1 × 好み位相クラスタ 0/½) の符号化ベクトル b_j = [side, 1, side·cos2πpref] そのもので、
**各 MN は 1 つの求心性クラスに位相固定している**。AHP (不応期 0.9 周期) の明けた直後の
窓に最初に到着する入力で発火するため、これは円周写像 θ_{k+1} = min{φ_j ∈ (θ_k+0.9, θ_k+1]} の
不動点 (位相同期ループ) であり、重みの argmax ではない。

### 4 種の構造的代理復号器 (スパイキング計算なし) の成績
| 代理 | 実配線 (代理/実測) | ヌル間相関 ρ (→実測誤差) | 判定 |
|---|---|---|---|
| 位相和 arg Σ W e^{2πi(pref+shift)} | 0.423 / 0.113 | −0.02 | 不合格 (基底位相 0/½ が相殺し破綻) |
| 閾値交差 (PSP カーネル和の最初の閾値越え) | 0.693 / 0.113 | +0.05 | 不合格 |
| 勝者総取り (重み argmax のクラス) | cond 2.02 / 2.33 | +0.21 (クラス数効果のみ) | 弱い |
| **円周写像 (PLL 不動点)** | **0.122 / 0.113、cond 2.28 / 2.33** | +0.03 | **実配線を再現、ヌル間は不可** |

### 実配線を 100 ヌル全てから分離する不変量
MN 内の入力求心性の符号化ベクトルのコヒーレンス、特にロール成分 (左右同側性):
実配線 0.946 vs ヌル中央値 0.413、**ヌル 100 個中 0 個が実配線に届かない**
(coh_mean 0.855 vs 0.694、coh_min 0.730 vs 0.588 も 0/100)。
解剖学的にはハルテア求心性の同側投射の反映。完全ヌルは電気経路の post 端を置換するため
1 つの MN に左右両側の求心性が混ざり、ロール成分 side·ω_x が相殺する。

### ヌルの失敗モードの線形代数
保存済み 40 ヌルの実測 S を SVD すると、悪条件 (cond 20〜60) のヌルの最弱方向は一貫して
[±0.7, 0, ∓0.7] = **ロール∓ヨー**。符号化でクラスタ 0 (cos=1) は b=[side,1,side] と
ロール・ヨー成分が同一なので、クラスタ ½ に固定した MN を失うとロールとヨーが分離不能になる。
実配線は hg3_R (R½) と i1_L (L½) がこれを担保している。WTA のクラス数効果
(クラス 2/3/4 で実測誤差中央値 1.38/0.84/0.56) はこのランク条件の反映。

### 限界 (正直に)
- 実配線の復号性能は構造だけから予測できたが、**ヌル集団内の誤差ばらつきはどの静的代理でも
  予測できない** (ρ≈0〜0.2)。実測では S の条件数が誤差を予測する (ρ=+0.64) が、その条件数
  自体がノイズ下の位相固定の不安定化 (どのクラスタにロックするか、R<0.5 で除外される MN、
  σ₁ が 3〜10 倍に跳ねる過感度 MN) という力学的現象で決まり、静的代理はヌルの失敗を
  過小予測する (代理中央値 0.23 vs 実測 0.61)
- 介在ニューロン経路 (1 ホップ) の寄与は未評価。抑制性入力は円周写像に自然に入らない

### 結論
配線特異性の線形代数的正体は「**同側にまとまった求心性→MN 結線が、各 MN を単一の
符号化クラスに位相固定させ、クラスの多様性 (両側 × 両クラスタ) がロール・ピッチ・ヨーを
分離する良条件の S を作る**」ことである。実配線ではこの条件が解剖学的に保証されており、
その帰結 (S の条件数と復号誤差) は円周写像という 1 次元の構造計算で定量的に再現できた。

## P2 補遺: リミットサイクル周りの Floquet 計算の失敗 (2026-09-02)

ポアンカレ断面 (羽ばたき平均 e_b1 の上向き交差) からの有限差分でモノドロミー行列を求めた
(floquet_cycle.py) が、|μ| ≈ 18〜25 /サイクルという、4 秒間有界にホバーする実測と矛盾する
値が出た。原因: 断面が整数ビート分解能しか持たず、摂動で交差ビートが 1 つずれるだけで
サイクル 1 ビート分の運動 (振幅 0.04〜0.18 rad) が差分に混入し、摂動 (0.01 rad) に対して
桁違いに大きい偽の乗数を与える。さらに 11 Hz のサイクルと 203 Hz のビートは非通約なので、
ビート写像の軌道は周期軌道ではなく準周期であり、Floquet 理論の前提が成り立たない。

正しい対象は 2 軌道差のリアプノフ型成長率 (hover_growth.py / floquet_check.py) であり、
それは既に「d≤1 で ≈1.00 (サイクルの位相方向の中立性)、d≥2 で正に転じる」と測れている。
固定点線形化の役割は「遅延に対する傾向と壁の位置」の予測であり、絶対値の一致は求めない。

## P4 の結果 (2026-09-02) — 歩行は結合位相振動子として記述できない

### 実験
walk_reflex.py (MDN 150 Hz + 反射 α=1.0、統合37 と同条件) を 5 s × 3 ラン。脚の遊脚/接地は
大腿・脛関節角の 3〜15 Hz 帯域通過 + Hilbert 変換で位相化し、z > 0.10 の直立区間のみ解析
(walk_phase.py)。最初の 6 s ランは 0.81 s で転倒したため無効 (前回記録)。

| ラン | 最終直立度 | 直立区間 | 判定 |
|---|---|---|---|
| r1 | −0.60 | 2.24 s / 5 s | 不採用 (<2.5 s) |
| r2 | −0.62 | 4.88 s / 5 s | 採用 (末尾で転倒) |
| r3 | +1.00 | 5.00 s / 5 s | 採用 (完走) |

同一条件でも 3 ラン中 1 ラン しか直立を保てない。5 s の前進は r3 で +0.03 m、r2 で −0.32 m (後退)。

### 位相コヒーレンス行列 Z_ij = ⟨exp(i(φ_i − φ_j))⟩

| 量 | r2 | r3 | 結合振動子なら |
|---|---|---|---|
| 脚の位相振動数 [Hz] | 5.1〜6.4 | 3.2〜5.8 (前脚 3.2/3.8、他 5.4〜5.8) | 全脚が共通振動数 |
| 非対角 \|Z_ij\| の範囲 | 0.14〜0.37 | 0.02〜0.52 | ロックなら > 0.8 |
| 主固有値 / 6 | 2.03 | 2.38 | 完全同期で 6 |
| 三脚歩容からのずれ [deg] | 37〜153 | 8〜126 | ≈ 0 |
| Kuramoto フィット R² (各脚) | 0.02〜0.12 | 0.01〜0.09 | > 0.5 |
| ヤコビアンの正の実部 | +6.8 | +7.5, +2.1 | なし |
| 遊脚率 | LF 0.85, LM 0.25 | LF 0.91, LM 0.09 | ≈ 0.3〜0.5 |

r2 と r3 で「どの脚同士が最も強くロックするか」も一致しない (r2: LH–RM 0.37、r3: LF–RF 0.52)。
最強結合の符号も両ランで反転する。

### 解釈
- **位相ロックが存在しない**。脚ごとの振動数がそもそも揃わず (前脚 3 Hz vs 他 6 Hz)、
  |Z_ij| は非同期の雑音水準 (5 s × 6 Hz ≈ 30 周期なら無相関で ≈ 0.18) と区別がつかない。
- **脚は「振動」していない**。前脚の遊脚率 0.85〜0.91、中脚 0.09〜0.25 は、脚が遊脚か接地に
  張り付いたまま小さく揺れていることを意味する。Hilbert 位相はその揺れを拾っているだけである。
- Kuramoto フィットの R² が全脚で 0.1 以下なので、結合係数もヤコビアン固有値も
  意味を持たない (前回、転倒ランで +39.8±28.5i が出たのと同じ「当てはまらないモデルの残差」)。
- したがって統合37 の歩行は「三脚歩容の創発」ではなく、MDN の緊張性駆動 + 局所反射による
  **前進しない足踏み** である。統合37 の記録 (前進 1 cm 程度、脚間協調は未検証) と整合する。

### 結論
P4 の仮説「歩行は脚位相の結合振動子系で、Z_ij と Kuramoto 結合から歩容の安定性が読める」は
**このシミュレーションの歩行には当てはまらない**。線形代数的解析の対象になる前に、
歩行そのもの (共通振動数を持つ脚周期と、脚間の一貫した位相関係) が成立していない。
Hopf 分岐図 (計画の P4 目標) は前提を欠くため着手しない。

これは P1〜P3 の飛行系との明確な対比である: 飛行では羽ばたきという強い搬送波と、
それに位相固定した感覚→筋の経路が存在し、遅い成分の線形化が意味を持った。
歩行ではその搬送波に相当するもの (CPG の共通リズム) がモデル内に無い。
腹髄の脚 CPG 回路 (MANC の脚運動前ニューロン群) をコネクトーム駆動で入れない限り、
歩容の位相解析は成立しない。これが次の課題の候補である (未着手)。
